# pi-task

`pi-task` — самостоятельный пакет для [Pi](https://pi.dev/). Инструмент `pi_task` показывает вопросы пользователю в терминале Pi.

Установите пакет из локальной копии командой `pi install /абсолютный/путь/к/pi-task`, затем перезапустите Pi или перезагрузите расширения. Для одной сессии используйте `pi -e /абсолютный/путь/к/pi-task/extensions/index.js`. Для изолированной установки задайте `PI_CODING_AGENT_DIR` с путём к новому каталогу в обеих командах. Установка из реестра станет доступна после публикации.

Передайте массив `questions` из 1–4 вопросов. У каждого есть текст `question`, заголовок `header` до 12 символов, необязательный `context` до 600 символов и 2–4 варианта `options`. Каждый вариант содержит уникальный `label` и необязательное пояснение `description`. Пример вызова есть в [английском README](README.md).

Вариант выбирается стрелками и Enter. Пункт **Type something.** открывает поле для своего ответа. При одном вопросе ответ отправляется сразу. При нескольких вопросах переключайтесь между вкладками и выберите **Submit** после заполнения всех ответов. Esc сначала закрывает поле ввода, а из экрана вопроса отменяет окно.

`details` и `structuredContent` содержат один и тот же результат, а `content` — его текст. Статус `submitted` возвращает упорядоченный массив `answers` с полями `header`, `kind` (`option` или `text`) и `label`. Статусы `cancelled`, `aborted`, `no-ui` и `invalid` возвращают пустой массив. Смысл ответа и правила утверждения определяет вызывающий навык.

Старое расширение настройки orca-pod может предоставлять `orca_pod_ask` одновременно с `pi_task`. Проверки пакета и логики запускаются командой `npm test` и требуют Node 18 или новее.

Сведения об исходном коде приведены в [NOTICE](NOTICE), условия лицензии — в [LICENSE](LICENSE).

Проверено с Pi 1.4.0 в отдельном каталоге агента. В терминале проверены выбор варианта, свободный ответ, отмена и совместимость со старым расширением настройки.
